# 📜 天道自动写作大阵 (The Heavenly Auto-Writer Array)

> “道生一，一生二，二生三，三生万物。代码生Bug，Bug生补丁，补丁生需求...” —— 《码农真经》

## 🔮 阵法简介 (Introduction)

本阵法（Project）乃是集天地灵气（GLM-4 API）与上古符文（Python）于一体的**全自动爽文生成引擎**。目标是炼制出一部百万字的传世经典，以证算力大道。

## 🛠️ 筑基法门 (Installation)

欲练此功，必先筑基：

1. **凝练灵气**：确保已安装 `Python 3.8+` 及 `uv`。
2. **开启洞府**：
   ```bash
   uv sync
   ```

## 🎮 运转周天 (Usage)

1. **配置阵眼**：在 `.env` 中注入你的 `API_KEY`（灵石）。
2. **启动大阵**：
   ```bash
   uv run main.py
   ```
3. **挂机飞升**：脚本会自动处理断网、报错、走火入魔等异常，直到写满 200 万字。

## 🧩 阵法架构 (Architecture)

- `novel_engine/core/world.py`: **三千世界生成器** - 负责生成地图、NPC、仇恨链。
- `novel_engine/core/ai_writer.py`: **神笔马良接口** - 负责与上界（API）沟通，具备“无限重试”与“断章续火”神通。
- `novel_engine/data`: **万物词库** - 蕴含亿万种功法、法宝名称。
